## Pizza-Hut-Sales-Analysis---SQL

Overview:
This SQL-based project analyzes Pizza Hut's sales data to uncover insights about customer behavior, product performance, and store efficiency. It focuses on optimizing decision-making by leveraging advanced SQL techniques.

Key Highlights:

Technologies: MySQL, CTEs, JOINs, Subqueries, Window Functions

Analysis covers: Top-selling items, customer segmentation, sales trends, and payment insights

Deliverables: Clean SQL scripts, result snapshots, and a concise presentation of findings
